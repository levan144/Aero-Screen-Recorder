# FFmpeg location

Place `ffmpeg.exe` here, or run:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\get-ffmpeg.ps1
```

The executable is intentionally excluded from Git because it is a large third-party binary.

The download script retrieves the FFmpeg essentials build published by gyan.dev. Review and retain the license files supplied with the selected FFmpeg build when distributing AeroRecorder.
